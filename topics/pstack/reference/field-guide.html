The prompt

/pstack:poteto-mode <goal>. <what you already know>. <constraints>.
done means <a check that can pass or fail>. show me <the proof>.

Leave out the how, any list of skills, and your theory of the cause (at first). Add "new task" when you switch subjects, "don't change any code yet" for read-only work, and "solo repo, no PR: commit on a branch and stop" when there's no remote.

What happens to a prompt

  1. Restate the goal, the problem and the smallest change
  2. Read the principles index
  3. Match a playbook, or figure-it-out
  4. Copy the playbook's steps into a todo list (skips stay visible)
  5. Run the steps, calling skills and poteto-agent subagents
  6. Verify on the real surface
  7. Open a PR (worktree, small commits, gh, ready)

Autonomy

Proceeds without asking on reversible work. Always pauses for force-pushes to shared branches, deploys, data deletion and customer messages. Phrases such as "don't stop", "going to bed" and "run until done" mean keep going.
