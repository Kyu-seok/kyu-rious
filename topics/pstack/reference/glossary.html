Reference · pstack

Glossary

Every lesson uses these words with exactly these meanings.

TermMeaning
pstackLauren Tan's (poteto's) plugin of agent skills, principles and playbooks, in cursor/plugins. MIT licensed.
poteto-modeThe router skill. It takes a goal, matches a playbook and runs it. In Claude Code you type /pstack:poteto-mode. Only you can start it; the model never invokes it on its own.
PlaybookA numbered list of steps for one kind of task, such as Bug fix or Feature. poteto-mode copies the steps word for word into the todo list. There are 23.
Skip lineskip: <reason> on a playbook step the agent chose not to do. It stays visible so you can check the choice.
figure-it-outA skill that writes a custom playbook when none fits, or when the work is large or will run unattended.
PrincipleOne of 24 short engineering rules, each its own skill, such as Laziness Protocol or Prove It Works. poteto-mode reads their index at the start of every task.
poteto-agentThe subagent type for work handed off inside a playbook step. It reads poteto-mode in full before it starts. In Claude Code it is pstack:poteto-agent.
RoleA job that pstack assigns to a model, such as bug-fix, judgment and prose or interrogate reviewers. Set by /pstack:setup-pstack.
PanelA role whose value is a list. One subagent runs per entry, so the list length sets how many run. Used by arena, architect and interrogate.
inherit-parent / autoA role value meaning "run on the main chat's model". On Claude Code, every Grok default becomes this.
BudgetThe reasoning level applied to every role: unlimited (max), large (xhigh, the default), medium (high), small (medium).
SurfaceWhere a behavior can be observed, such as the UI, CLI, API or a stored value. pstack verifies on the surface where the problem appeared. A check on any other surface isn't a pass.
Verification skillA skill local to the project (verify-<app>) that teaches agents to drive your app the way a user would, so they can prove their own work. Created by create-verification-skill.
Claude Code adapterdocs/harness/claude-code.md, the table that maps Cursor names (tools, models, paths) to Claude Code.
